What Is Cloud Computing?

David Chen
Technology • 6 min read • ↓ SCROLL DOWN FOR KEY

Cloud computing means using computing resources (servers, storage, databases, software) over the internet instead of owning and maintaining them yourself[cite: 30].

How it works

When you store photos in Google Photos, stream a movie on Netflix, or use Microsoft 365, you are using cloud services. The actual hardware sits in large data centers operated by companies such as Amazon, Google or Microsoft. You access those resources through the internet[cite: 30].

Main types of cloud services

  • IaaS (Infrastructure as a Service) – virtual machines, storage and networking[cite: 30].
  • PaaS (Platform as a Service) – tools for developers to build and deploy applications[cite: 30].
  • SaaS (Software as a Service) – ready-to-use applications like email, office suites or CRM tools[cite: 30].

Why it matters

Cloud computing lets individuals and businesses scale quickly, pay only for what they use, and access services from any device with an internet connection. It also shifts the burden of hardware maintenance and security updates to the provider[cite: 30].

Understanding the basics of the cloud helps you make better decisions about data privacy, cost and which online tools to trust[cite: 30].
